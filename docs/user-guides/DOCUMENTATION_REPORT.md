## 必须保留的业务结论

志愿者提交直接形成正式考勤；两小时从首次成功提交起算，修改、撤回和重新提交均不续期。任何异议记录或管理员更正保护整个任务结论。学生异议一次审核，旧人工提交审核与旧初核不能作为当前操作流程。

普通考勤更正的已部署管理入口在“查课安排 → 详情与点名册 → 更正”。教工本人有效授课关系另有“我的授课”受限更正与历史；归档特殊更正有更严格角色、原因与范围限制。

任务“历史保留删除”仅退出日常列表，原考勤统计和历史不变；未使用任务可能按删除预览彻底删除。不能混同撤回、停课免计或承诺所有删除均能恢复。
