> 测试状态说明：本文件是初始样本设计，不是当前数据库快照。任务5中V3已开通资格作为手工正向对照；任务6在独立QA副本重导V1/V2并生成未来任务294。初始阴性样本不能直接当作现有无资格人员使用。任务5公开测试学院与任务6QA副本的写入分别记录，见最终报告。

本文提供任务 5 可按步骤准备的最小数据；**当前仅定义，未在本轮向已确认的测试库新建这些资料**。没有真实姓名、学生名单、照片、密码、绑定码或令牌。账号登录凭据由环境维护者通过现有安全渠道提供，不写入手册。

## 环境和日期

- 用户已确认当前系统数据库为测试库并授权模拟操作。后续浏览器功能验收可在该测试系统中限定合成学院、学期与对象执行，先核对实际 API 目标；无需把浏览器操作等同于重建数据库。会删除重建表的 MySQL 自动化集成夹具必须另用确认过的独立 `*_test` 数据库。需要可控时钟或故障注入时另用隔离 QA 进程和文件目录。
- 不把现有“软件学院（测试）”或任何现有生产学院当作可清空沙盒；其两个班级和关联历史继续保留。
- `D0` 为验收当天北京时间；`D-1`、`D+1` 分别为前一天和后一天。`T0` 为某项用例首次提交成功的服务端时刻。独立验收学期至少覆盖 D-1、D0、D+1，其第一教学周周一由 QA 校历确定，页面周次与真实日期一致。
- 边界用例需要超过两小时时，使用单独任务或等待真实时间。自动化如采用受控测试时钟，只能作用于隔离 QA 测试进程；不得修改生产时间、生产业务行或把窗口改短后声称通过真实两小时验收。
- 每次用例从指定初始状态开始；更正、异议、撤回等相互影响的场景使用不同任务，不让前一项测试破坏后一项前置条件。

## 错误文件与最小复现

- 重名：责任表只有“验收同名教师”，不写工号；应提示补充身份依据，不自动选本院同名者。
- 编号姓名不符：QAT001 对应“验收辅导员乙”；应要求核对，不能按姓名覆盖另一人。
- 无权限类型：负责人选择含教职工表头的文件；应保留识别结果并提示无权，不改走课表解析。
- 独立保存：一份正确学生表、一份缺必填列课表；确认正确资料组后修正失败文件，原成功组无需重导。
- 首表边界：首表 S1/S2，次表含 S3 或未知学号；次表不参与身份冲突与合并。此规则仅适用于对应的学校考勤名单格式，不能推广为所有 Excel 均忽略其他表。
- 重复/过期：重复确认同一有效预览不重复创建正式资料；改变学院、学期、权限或原始资料后必须重新预览，过期/修订不符应拒绝。
