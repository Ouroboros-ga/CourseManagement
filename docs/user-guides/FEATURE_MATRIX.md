## 已取消流程与已知差异

- 志愿者提交不再经过人工审核；旧审核写入流程已移除。不能把旧权限名、历史字段或旧测试当成当前操作要求。
- 学生异议一次审核；旧初核写入被拒绝，旧终审路径仅兼容。不得按“先初审再终审”编写新验收。
- 当前小程序异议诉求固定为正常出勤，尚无诉求类型选择器。后端可表达其他判定不等于学生页面可以选。
- 当前管理端普通更正表单和小程序异议表单要求填写原因；后端对应字段可选。先按实际页面要求操作；这是端侧与契约的差异，未在本轮修复。
- 小程序附证明异议存在大文件编号转数值后可能失真的源码风险（J28），尚未真机复现，不能声称该链路已通过。
- 小程序纠错截止文字存在格式缺陷的源码证据；是否允许修改由服务端返回决定。尚未真机复核，不能把显示问题描述为窗口已失效。
- 学期设置仍有旧“重置本学期业务数据”按钮，但当前范围模式的服务端守卫不允许该旧流程。本轮未点击，不列为可用清理手段。
- 无完整通用历史版本列表不等于历史未保存：提交修订、撤回、更正仍保留记录，部分教工本人视图和归档视图有局部历史展示。
- N01—N03 是范围限制，包含首期明确不承诺的能力，不能将它们统计为本轮新增 Bug。B01—B09 是端侧接入缺口，不伪装成完整交付。

## 四类身份边界验收

| 身份 | 允许的核心路径 | 不因身份自动获得 |
| --- | --- | --- |
| 教师管理员 | 本院资料、组织、任务、考勤、异议、授权与报表 | 全校账号/日志权限、外院数据、仅超管的公共配置写入 |
| 学生工作负责人 | 有效本院任命及功能设置内的导入、任务、考勤、异议、报表 | 教师建号、学籍/教工维护、归档特殊更正、全部组管理或全校统计 |
