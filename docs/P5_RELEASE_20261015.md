## 部署与边界

待本轮提交推送后部署。部署脚本 `deploy/production/deploy_campus_p5_20261015.py` 验证候选哈希与服务器验收证据，备份并校验校验和后升级增量结构，验证原业务行数不变，检查候选服务，再切换后端/Web指针并开启 `ACADEMIC_PUBLICATION_ENABLED`。

P2全业务与P3/P4排班开关保持关闭，不能把 P5 上线写成 P2—P4 已整体生产验收。当前代码还含上一阶段实现；P2—P4完整验收保留在原计划，后续单独推进。已有路由验收发现学籍交接学院别名可能被通用读取路径抢先匹配，作为未完成项保留；与本轮P5发布/个人课表路径不冲突。

失败时恢复旧环境配置、后端及Web指针并重启，保留兼容增量结构。已产生个人副本/发布事实后，不直接降级删除新表；完整数据回退使用发布前经校验的备份。线上最终版本、时间和备份路径将在部署成功后补充。
