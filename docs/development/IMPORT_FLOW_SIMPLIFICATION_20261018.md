# 教务导入操作简化

日期：2026-10-18。开发基线：`5848791`。状态：隔离工作区已实现，已纳入本次提交，尚未部署。本记录不替代当前实施状态入口。

## 问题与结果

新版卡片首页增加一次选择，文件框丢失文件夹和 ZIP 入口；预览默认堆叠问题表、实体差异和确认步骤。调整为直接在导入页面选择文件夹、ZIP 或多个表格，读取后先显示文件结果与新增/修改概要，再明确确认一次。

- 保留资料类型选择，默认教务原表；普通课及平台长表格式放入更多设置，不要求日常操作重复配置。
- 文件夹支持子目录；非表格与临时文件明确列为未选入。ZIP 支持同类型表格，保持中文成员路径，只生成草稿，不调用旧版自动写入的 bulk 接口。
- 每个文件显示识别到的班级/人数/课程安排、可否导入及首个需要处理的问题；详情按需展开，展示将保存的字段及修改前内容。
- 读取失败文件留在结果中；未明确排除前禁止确认成功子集，不静默部分导入。后台阻断问题仍阻止整批确认。
- 未完成记录可“继续核对”；过期、原资料变化或跨学期记录仍需按服务器校验重新处理。
- 改格式不会清空刚选好的文件；换账号、学院、学期或授权修订会清空旧范围数据，并丢弃过期响应。
- 保存仍绑定确切批次 ID 和预览修订，使用现有事务、权限与审计。预览直接点击确认后保存，不再增加一个内容重复的确认弹窗。

## 接口与范围

新增 `POST /api/v1/colleges/{cid}/imports/confirmation-set/zip-preview`：multipart `file`、`target`，可选 `semester_id/teaching_class_id/course_type_id`。返回 `files`（成员预览）、`errors`（未读入成员）和 `business_data_applied=false`。之后仍调用已有 `preview/confirm`，不新增正式业务写入逻辑。

保留每批 20 个表格、单文件/压缩包 10 MiB、ZIP 解压合计 50 MiB 和 200 目录项上限；不接受加密、链接、嵌套 ZIP、不安全路径、重复路径及其他格式。未实现混合类型自动识别；名单和课表请分批处理。不提供 RAR/7z 解压。

## 后续截图阻断修复：学校模式误要求学院映射

2026-10-18 用户反馈“请先发布本学院作息中的教务小节映射”。源码及内存 SQLite 复现证明：`ScopedImporterService.grid_slot_mapping` 无条件读取学院默认作息，而其他正式时间计算在学院独立作息关闭时仍使用学校 `PeriodDefinition`，两条路径的模式判断不一致。

已修复：学院独立作息关闭时复用已有学校节次映射逻辑，学校十二节配置保留原始小节（含 10—11 节）；独立作息开启时仍要求显式学院映射，不自动猜测或更改配置。错误提示区分学校节次缺失与学院映射未发布，并说明处理位置。

这不是取消校验，也不在上传预览时隐式发布学校/学院作息。原失败草稿保存的错误和空解析结果不会随代码升级自动修复，需要重新读取原文件。新增两项回归分别覆盖学校模式原始节次和学院模式保持阻断；既有显式映射导入回归继续核对。原验证阶段未发布；后续本批次已随应用源码 `bed04b8` 部署，生产配置未改变，见[发布记录](PERSON_RELATION_RELEASE_20261018.md)。

## 下一步产品讨论：统一资料导入工作台（待开发）

2026-10-18 用户明确将教职工档案、行政班班主任/辅导员责任关系纳入学院必备资料；教学班补充名单与选修/分层长表保留补充用途。用户提出统一上传、预览和确认界面，本节记录设计方向，不代表本次发布已实现。

- 必备的是数据齐备，不是每学期重复上传文件。行政班/学生、教职工和班级责任关系跨学期保留；课表随学期维护。任课关系优先由课表工号及档案关联，不要求逐教学班再填一次。
- 统一文件、文件夹、ZIP 入口，已知格式识别并允许纠正类型，提供各类标准模板或包含独立工作表的资料包；不宣称任意教务原表自动兼容。
- 联合草稿应先解析全部来源，再按档案、班级、责任关系、课表及名单依赖核对，避免上传顺序影响关联。工号/学号作人员主键，姓名用于核对，缺失或重名不得猜测授权。
- 预览按业务资料展示新增/更新/不变、待关联及冲突；来源文件/工作表/行号可追溯。仅对受上限约束且已实现联合事务的选定集合承诺一次确认原子写入，不把原有逐文件提交描述为跨资料原子提交。
- 现有确认集合拒绝混合无学期教职工档案与学期资料；当前 ZIP 针对同一资料类型。统一 UI 还需后端依赖草稿改造，不能只把现有多个表单摆在一起。
- 排班前还需组成员、负责人及资格齐备；资格底册不能代替组成员关系。人员缺项影响对应教工/排班能力，不影响已完成历史记录。
- 待讨论补充：组织成员批量表、学籍与责任关系生效日期、非行政班课程实际名单和免查课程规则。选修资料不作为默认启动必填，早晚自习继续使用批量生成入口。
