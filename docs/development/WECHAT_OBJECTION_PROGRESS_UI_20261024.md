## 交互

在原考勤记录的申诉详情弹窗增加“办理进度”和“刷新进度”。每次打开只请求当前选中申诉；先读取功能标记，明确关闭时隐藏进度、不请求进度接口。标记缺失或读取失败展示错误，不推断成已关闭、未提交或审核通过。

仅展示公开阶段、说明及正式final_status，不复制内部任务、凭据、材料或模型意见。进度读取时清除旧展示；失败保留正式记录并支持显式刷新，不重发申诉。服务端已经结案而列表快照尚未更新时，显示正式通过/驳回并提示下拉刷新考勤，不自行改判旧考勤。

关闭弹窗、切换申诉、离开或卸载页面会废弃旧请求。检测到本地登录凭据变化时关闭详情、清空旧列表，并提示下拉刷新；这也可能发生在同账号自动刷新Token后，宁可要求重新读取，不把旧请求结果挂到变化后的会话。Token仅作内存中的请求上下文比较，不进入页面数据、日志或持久化新增字段。

记录页已启用下拉刷新，并在重新进入时清空旧详情；列表响应也有序号和会话上下文校验。读取失败显示失败状态，不显示为“暂无记录”；申诉列表读取失败时仍保留考勤，但不把未知状态当作没有申诉，也不显示提交新申诉的入口。比较申诉编号使用十进制字符串长度及字典序，避免BIGINT转Number后选错最新申诉。历史initial_*只作历史展示，当前进度和正式结果不由旧初核字段推断。
