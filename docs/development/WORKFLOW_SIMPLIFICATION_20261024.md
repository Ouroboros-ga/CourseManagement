# 管理流程精简实施计划

目标：减少重复确认、无关预览失效和规则维护断点，保留真实冲突、权限、审计与历史快照。

架构：复用当前 FastAPI Service、不可变配置版本及 Vue 编辑器；不增加审批状态、通用工作流引擎或迁移。规则编辑器负责当前表单，组织详情负责学期上下文，管理组件负责调用现有影响预览与保存；作息高级组件继续复用。

## 1. 配置与影响处置

- [x] 组织/课程类型元数据无变化时不写版本；名称、说明、颜色、排序变化只留审计，不生成执行影响。
- [x] 相同组规则不生成新版本。真正变更继续确认未来任务，并保留原任务快照。
- [x] 任务取消、有效改派成功后，在同一事务自动关闭匹配的影响项；未解决的配置时间/分类影响不因无关写操作关闭。
- 涉及：`organization/service.py`、`future_impact.py`、`impact_service.py`、`inspection/service.py`、`assignment_plan_service.py`，对应 Web 管理组件。
- 验收：无变化版本不增、改名无影响项、真实变更仍拦截、自动关闭具有审计且失败回滚。

## 2. 本学期规则与预览范围

- [x] 增加直接发布本学期规则接口，复用组权限与版本锁；归档学期不可写。
- [x] 本学期编辑入口统一，不要求通过复制成员才能改规则；组织默认底稿单独维护。历史版本不覆盖。
- [x] 成员导入/学期复用指纹移除无关学院配置计数，保留实际输入、目标状态和权限复核。
- 涉及：`organization/router.py`、`service.py`、`volunteer/preparation.py`、`member_batch.py`、`OrganizationDetail.vue`、`GroupManager.vue`。
- 验收：已复用且有未来任务的学期可经影响确认修改；历史任务不变，越权/旧版本/归档拒绝；无关组织变化不使预览失效，相关输入变化仍失效。

## 3. 作息操作收拢

- [x] 首屏保留当前作息、学校版本采用及停补课；映射、特殊方案和教学班绑定默认折叠，底层能力保留。
- [x] 发布特殊作息时先保存当前编辑，再预览和确认发布；中途取消仅保留草稿，明确反馈，不丢弃编辑。
- [x] 学校版本采用使用一个有影响明细的确认动作，移除重复的知晓勾选。
- 涉及：`CollegeTimeConfiguration.vue`、`SchoolTimeDefaults.vue`、`TimeProfiles.vue`。
- 验收：类型检查/构建、定向交互与保存/取消/失败路径；不做全量生产数据验收。

## 交付边界

本轮实现及本地定向验证；不自动更改生产配置、不迁移历史记录。提交、推送、部署分别记录，不以本地完成代替上线。


## 实现与交接

- `POST /api/v1/colleges/{cid}/groups/{rid}/configuration/publish?semester_id={sid}`：直接保存指定学期规则。沿用原请求体、组级 `lock_version`、范围授权及 `future_impact_revision`。省略学期仍维护组织默认底稿；相同配置返回原版本。旧版本缺省字段按既有默认语义比较，不因补齐字段产生新版本。
- 配套 `GET /api/v1/colleges/{cid}/groups/{rid}/impact?configuration_only=true&semester_id={sid}`：只预览本学期规则影响。省略学期且带 `configuration_only=true` 时，仅考虑仍沿用默认底稿的学期，不要求再次确认已经独立的学期。
- 无变化仍复核当前权限与版本；已归档学期、过期组版本、越权范围继续拒绝。学期版本通过现有 `GroupSemesterPreparation` 指针管理，不修改历史版本或任务，亦不要求重新复制成员。
- 任务取消、人工/自动排班及排班确认计划共用事务内的影响自动结清函数；同一受派未变化不会误结清，旧处置记录仍保留。旧待办保留人工核对入口，不静默扫描改写生产历史。
- 学校版本采用与学院作息发布改为“先预览、再确认发布”，确认按钮本身表达保留已有任务快照，不重复要求勾选知晓。高级作息方案发布先保存当前编辑，取消或409保留草稿；高级配置折叠不删除底层能力。
- 本轮不修改小程序页面，无数据库迁移或生产业务数据修复。

验证结果、实际提交/部署状态见 `IMPLEMENTATION_STATUS.md` 顶部；本地模拟界面使用合成人员和任务，不代表线上真实数据验收。


## 追加决定：移除志愿者跨院支援

- [x] 删除 Web 支援切换、增改授权和全校候选搜索；成员页只保留本学院学生。
- [x] 删除 `/support-authorizations` 的全部读写/影响路由及 Service 分支；移除 `school` 候选参数、排班资格索引的支援查询与指纹依赖。
- [x] 单人、批量、Excel 导入、复用学期和重新启用统一校验本院学籍；本院同人多组不变。旧跨院成员可停用，但不得重新启用或新排班。
- [x] 组织总览只统计参考日期属于本学院的有效成员，旧支援授权不再造成“可排班”假象。
- 历史 `volunteer_group_support` 表映射仅供历史追溯及通用引用保护，不参与授权或排班，不执行删表或历史受派删除。既有受派可沿原流程完成提交、更正或由管理员改派/取消。
- 删除学期准备响应中不再有业务含义的 `support_grants_copied` 字段，Web 类型同步更新。小程序页面不变；新排班候选仅返回本院成员，历史受派记录保留。
- 上述取消的是志愿者支援，不是超管显式授予的跨学院管理权限，也不改变共享教学班及正式考勤归属。
