# 智能资料导入：已有预览的助手核对

日期：2026-10-24。分支：`future/agent-dev`。本地候选，未部署，未与腾讯云真实工作流联调。

## 已接通的业务链

教师通过现有资料入口上传文件或压缩包，固定程序拆包、识别类型并生成预览。管理助手获得当前教师已创建的预览编号后，可调用 `import_preview_review` 重新核对变化。工具复用 `ImportConfirmationSet.preview`，不会另写解析、姓名匹配、冲突判断或保存算法。

助手看到每份预览的新增、更新等变更数量，错误和提醒数量，以及当前是否具备确认条件。存在阻断问题时，引导教师回资料核对页面查看具体问题；没有阻断也仍需人工确认保存。`can_confirm=true` 只是本次读取时原业务校验的结论，不能当作授权票据或后续保存保证。

工具不返回原始文件内容、姓名、学号、工号、变更前后明细、原始问题文字、文件名、确认 revision 或确认保存请求。具体冲突明细仍由原登录页面按原权限展示。文件名和表格单元格不能充当智能体指令。

## 工具与身份

- 工具名：`import_preview_review`；仅 MANAGEMENT，HTTP 和 MCP 通过同一固定目录发布。
- 参数：`{"batch_ids":["123","124"]}`，1—100 个不同的正数 BIGINT 字符串，不接收学院、用户、角色、保存或审批参数。
- 学院、教师、学期从后端运行身份取得，开启学院配置和学院业务范围后才可执行。
- 每次复用 `import.execute` 及各资料类型的原管理权限。预览须属于当前学院及当前教师；含学期资料必须属于当前运行学期，教学班所属学期也重新核对。无学期教职工资料仍走原独立核对规则。
- 过期、已确认、源资料已变化、重名、跨文件冲突等仍由原核对服务裁决。工具只统计问题，不替教师补工号或自动选同名人员。
- 持久只读队列可执行该工具，使用原学院授权范围摘要；取消、过期会话及迟到结果继续遵循既有任务规则。

结果示例（示意编号）：

```json
{
  "kind": "IMPORT_PREVIEW_REVIEW",
  "college_id": "10",
  "files": [{
    "batch_id": "123",
    "target": "volunteer",
    "changes": {"CREATE": 12},
    "error_count": 0,
    "warning_count": 0
  }],
  "can_confirm": true,
  "requires_human_confirmation": true,
  "business_data_applied": false,
  "message": "请在资料核对页面查看具体变化和冲突，人工确认后保存。"
}
```

原确认页面会重新读取资料变化和 revision；提交保存时再次执行原业务校验和事务。没有注册供模型调用的确认保存工具。
