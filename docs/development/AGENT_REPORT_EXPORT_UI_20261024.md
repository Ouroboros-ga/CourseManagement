# 助手报表下载卡

日期：2026-10-24。分支：`future/agent-dev`。状态：管理端本地候选，未部署；真实助手会话、ADP及任务链接分发尚未联调。后端准备/下载边界见[导出准备](AGENT_REPORT_EXPORT_20261024.md)。

## 当前入口

已有导出准备队列任务可通过 `/dashboard/reports?assistant_task_id={任务编号}` 打开统计页中的“助手准备的报表”。不带该参数时不加载卡片、不改变原导出入口。任务编号不是授权凭据；卡片通过原Bearer请求 `GET /api/v1/assistant/tasks/{id}`，服务端复核任务本人及当前统计范围。没有提供前端运行密钥或公开签发运行身份。

QUEUED/RUNNING提示等待并提供显式刷新；FAILED/CANCELED不给下载操作。仅SUCCEEDED且结构化结果为已知导出准备类型时展示按钮。未读到可信结果时不依据模型文本或用户URL构造报表。

## 下载行为

卡片明确显示“文件尚未生成”。点击“生成并下载报表”才向既有统计导出入口发起带当前登录身份的GET，按最新数据生成。任务时间范围单独展示；下方看板周次选择不会修改已准备任务的范围，学院和学期必须与当前工作区一致。

适配层验证三种固定格式、当前学院/学期、规范字符串ID、周次或完整且不超过93天的日期窗。拒绝额外查询选择器、无效日期、外部URL或与固定路径不一致的下载描述。实际请求重新按白名单构造同源路径，不使用模型传来的URL。BIGINT不经过Number转换。

共享HTTP客户端增加download模式，复用现有Bearer、Cookie和401单次刷新，读取二进制及服务端Content-Disposition文件名。旧JSON/blob模式保持原返回形状。下载响应类型须符合报表格式或octet-stream，200 JSON不会被保存为Excel。只有收到文件并发起浏览器下载后提示成功，不声称操作系统已经完成保存。

重复点击不重复请求；下载失败清除旧操作，要求刷新，不能自动切学院、扩大范围或重发任务。账号、学院、学期、权限版本变化或卸载组件后，旧响应不得触发文件保存。授权版本变化使原任务在后端不可重放时，显示错误并要求回助手重新准备，不重新授权旧结果。
