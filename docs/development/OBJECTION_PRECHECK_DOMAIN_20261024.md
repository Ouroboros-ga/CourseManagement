# 申诉预审：领域记录与事务候选

日期：2026-10-24。状态：本地候选，未提交、未部署、未调用真实ADP。产品范围见[五模块设计](../product/AI_COLLABORATIVE_PLATFORM_FUNCTIONAL_DESIGN.md)，总体进度见[实施状态](IMPLEMENTATION_STATUS.md)。本文只记录预审领域基础，不能作为完整申诉预审验收。

## 已有行为

- `AGENT_OBJECTION_PRECHECK_ENABLED` 默认false。开启时，学生创建申诉的原服务在同一事务登记独立任务；登记或后续创建审计失败时整体回滚。关闭时保持原创建行为。
- 独立保存学院策略、策略版本、真实授权人、真实发起人、环境、资料摘要、执行批次与建议。不复用已停用的 `initial_*` 历史字段，不触碰正式考勤、考勤版本或终审字段。
- 策略设置要求数据库中的教师管理员或超管身份，以及本学院完整的申诉读取和终审权限。执行开始和结果保存时重新检查实际账号、角色、范围和当前策略，不创建虚拟管理员会话。
- 策略未配置或未开启时登记 `FAILED / POLICY_UNAVAILABLE`，不假报已经预审。未知学院的遗留资料登记 `SOURCE_SCOPE_UNRESOLVED`，不根据当前学籍猜补学院。
- 同申诉、资料摘要、策略版本、环境只登记一次。资料摘要包含申诉理由和诉求、当前考勤认定与版本、有效/撤回状态、任务快照及关联文件元数据/哈希，不含对象路径或签名URL。
- 结果只能给出支持建议、需补充信息或需人工核验，附材料引用、观察与问题。不能提交终审状态或最终考勤类型；引用文件必须属于绑定申诉，结果限32KiB。
- 考勤/理由/材料变化、记录撤回或人工先终审时，迟到结果记为STALE。旧执行批次不能提交；已保存建议在资料变化后不再作为有效结果返回，历史记录仍保留。
- 完成审计使用系统来源并记录实际策略授权人，不把AI冒充人工审核人；审计不保存材料正文、建议全文或临时执行令牌。

## 调用与并发边界

`ObjectionPrecheckService` 保留为内部领域服务，对外由[专用预审运行与3个工具](OBJECTION_PRECHECK_RUNTIME_20261024.md)约束调用。[预审派发器](ADP_OBJECTION_DISPATCH_20261024.md)已有本地候选，尚无前端按钮，消费者未启动。`enqueue` 是flush-only源事件，调用方负责真实入口鉴权、持有原申诉创建锁并提交；它不是可直接开放给模型的授权入口。

`begin/finish` 在学院及策略范围检查后按查课任务→考勤→异议→预审任务→材料加锁。取得锁后保留当前读的值，不再用普通SELECT覆盖锁后值；真实MySQL的REPEATABLE READ竞争仍需验收。登记时只读取策略快照，避免持有考勤/材料锁时反向等待策略锁。后续云端调用必须在事务外执行，保存结果时重查策略与资料；不能为等待模型持有数据库事务。

`begin_in_transaction` 现为无commit领取核心，派发器将领取、身份及云实例追踪同事务提交；原 `begin` 保留提交包装。已有追踪的任务按云实例租约恢复，明确拒绝可有界重试；没有追踪来源的旧RUNNING任务不能自行重派。执行批次值只在后端传递，运行绑定保存其摘要，不能直接放入模型提示词。`finish_in_transaction` 用于与运行完成回执同事务提交；原 `finish` 保留提交包装。真实ADP和MySQL验收尚未完成。

## 材料受限读取（内部候选）

- `case_get(job_id, attempt_token)` 只返回绑定申诉的理由、诉求、考勤版本/认定、课程日期节次/班级快照和材料元数据；列出材料元数据也检查原FileService访问权限和证明材料类别。不返回学生编号、授权人账号、对象路径或下载链接。摘要最多32KiB、材料最多20份，超限明确转人工，不截断后继续生成结论。
- `file_access(job_id, attempt_token, file_id)` 每次重查实际策略权限、任务状态、批次和资料摘要，并核对文件属于该申诉且类别为OBJECTION_PROOF。复用原FileService逐文件鉴权和可访问状态检查，不因预审策略绕过原文件权限。
- 临时访问链接沿用原代理签名，时效取原文件配置、文件剩余保留期和60秒上限的最小值。未完成申诉的证明材料沿用原有“到期但关联待审申诉仍可访问”规则。原FileService调用未指定新内部上限时行为不变。
- 内部读取方法先完成短事务并释放锁，再由未来工作流取文件；不在持锁期间下载材料或等待模型。审计仅保存任务、申诉、策略和文件编号，不保存签名链接或材料正文。已签发链接沿用原机制，不能承诺关闭策略后即时撤销链接。
- 建议仅使用材料编号引用。结果Schema拒绝常见HTTP网址与签名下载串，避免把临时链接直接抄入建议；这不替代云端载荷/运行历史脱敏验收，也不构成对任意编码文本的完整秘密检测。
- 新增17项材料读取测试，实际调用原FileService，只有存储签名边界使用合成适配器。涵盖跨申诉文件、旧批次、完成后读取、资料变化、策略关闭、原文件权限拒绝、误关联其他类别、到期材料规则、60秒上限、原时效兼容及下载链接回填拒绝。预审领域与材料合计35项通过；不是公网下载、真实存储或ADP材料读取验收。

材料扩展后的组合回归为208项通过，覆盖原文件/教工材料权限、原一次人工审核、申诉范围、网关/队列和换班路径。Docker守护进程本轮复核未运行，真实MySQL竞争验证尚未执行。
