# 排班推荐核对页面改版

## 目的与实现

原排班推荐将任务大整数编号、志愿者编号与警告拼成长文本，难以核对人员和时间。现统一改为宽表格对话框：

1. 顶部显示执行组、学期、目标范围、日期与待排/拟派发/未分配数量。
2. 拟派发表格分列展示课程及教学班、日期节次及教室、志愿者姓名及学号/当前班级、中文规则提醒。内部 ID 继续保持字符串，仅作为关联键。
3. 未分配单独查看并显示代表原因；不把该原因解释为所有候选人同一种拒绝。支持搜索与50条分页，搜索只影响展示，不改变确认的集合和数量；切换标签清除旧搜索。
4. 底部明确“确认派发 N 项”，未分配项目保留待处理。返回调整、关闭、路由/身份/学院/学期等上下文变化均不确认；零分配不提供误导性的派发按钮。
5. 人员姓名由后端对拟派发账号进行一次 SQL 列投影，关联现有学籍，保留学号前导零。不逐行请求，不返回完整候选池或账号敏感字段，不以姓名推断身份或授予权限。

本次不改变排班算法、资格、冲突、配额或冻结确认集合，不创建实际业务排班，不新增迁移、权限或开关。展示资料不写入计划 payload，不进入确认 revision；提交仍传原精确任务/人员/警告。

- Vue 类型检查及生产构建通过，保留既有大 chunk 提示。受限文件权限的首次 Vite 构建 EPERM 不算通过，正常权限构建已通过。
