# 志愿者组织操作流程重排

2026-10-20。用户确认执行组织列表→组织详情的重排。本轮只调整后端既有能力的 Web 呈现，不改权限矩阵、数据库、历史任务或生产开关。

## 交互与组件边界

- `OrganizationsView.vue`：页面入口，只提供组织管理与全部志愿者；兼容旧标签链接。组织列表和详情均显示学院、学期上下文。
- `GroupManager.vue`：组织列表、下一步提示、新建与更多管理操作；URL 保存当前组织，返回和刷新保持上下文。编辑、停用、删除、负责人交接保留已有守卫与影响确认。
- `OrganizationDetail.vue`：固定组织的成员、实际规则与准备清单，提供前往查课安排和可选“复用上学期”。默认规则与冻结的学期规则分别标注，不能把修改默认规则说成修改已冻结规则。
- `useOrganizationOverview.ts` / `organizationReadiness.ts`：读取所选学期规则与成员，导出配置准备状态。读取失败不得显示零人或可以排班；账号/学院/学期变化丢弃迟到响应。
- `GroupMembers.vue`：简化模式直接展示成员表与添加/Excel 操作；请假、支援、粘贴学号置于明确入口。加人仍通过现有学籍核对并在有权限时同时开通资格。
- `GroupSemesterPreparation.vue`：固定当前组织，改为可选复用操作，无历史来源时解释如何直接添加成员。
- `GroupRuleEditor.vue`：按课程类型、班级、本人冲突、次数上限、特殊设置分组；不改变原配置字段或含义。
- `StudentDirectory.vue`：志愿者名册隐藏账号统计和 UID 等实现信息；名单维护回归学生入口，查课安排回归查课入口。

## 实施顺序与检查

1. 为准备状态与上下文切换补失败用例，保留未知、无成员、停用、归档及开关关闭等差异。
2. 实现列表和详情；选择组织后不再重复选组，复用原成员、导入、请假、删除与交接服务。
3. 整理成员添加、Excel、可选复用和规则表单；保留缺失资格权限的明确提示，不能静默授权。
4. 保持旧入口可达，查课跳转携带组/学院/学期。检查深链无权或组删除后回退行为。
5. 运行相关 Node 用例、类型检查和生产构建，用模拟 API 做组织新建、成员导入/添加、复用入口及上下文切换的浏览器检查；不向生产写数据，不扩大到全系统测试。

本轮不增加学期规则任意覆盖入口。已冻结规则只读并说明来源；原来的默认规则修改和未来影响确认继续可达。是否提交、推送或部署以当前实施状态和交付记录为准。
