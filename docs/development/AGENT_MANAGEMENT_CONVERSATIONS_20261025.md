# 管理助手持久会话与登录 API

日期：2026-10-25。分支：`future/agent-dev`。本地候选，默认关闭；未部署、未调用真实腾讯云。

## 用户与业务链

教师在当前学院、学期创建会话，再发送问题。后端验证真实登录会话及原业务范围，保存排队轮次和运行，由独立聊天消费者调用新版 ADP 对话适配器。客户端查询正式回复与本轮真实任务操作；报表和资料核对仍打开原页面，由本人点击下载或确认保存。

一轮对话结束不等于业务作业完成。模型文字里即使出现任务编号，也不会自动变成业务操作；后端只查询本轮运行实际创建、属于同一账号和来源会话、且为固定报表／资料读取工具的任务，并用原固定页面函数生成操作。

## 登录接口

三个操作仅在 `AGENT_TOOLS_ENABLED` 挂载，继续使用原 Bearer、当前用户和 SessionId 依赖，成功响应设 `Cache-Control: private, no-store`。ID响应为字符串。

| 方法与路径 | 输入 | 返回 |
| --- | --- | --- |
| POST `/api/v1/assistant/management/conversations` | `college_id`、`semester_id`，规范 BIGINT 字符串 | 会话编号、状态、空轮次列表 |
| GET `/api/v1/assistant/management/conversations/{id}` | query：当前学院、学期；可选 `before_turn_id` 游标 | 当前状态、最近20轮及更早游标 |
| POST `/api/v1/assistant/management/conversations/{id}/messages` | 当前学院／学期、`text`、`request_key` | 已入队轮次编号及当前快照；通过GET查询结果 |

发送示例：

```json
{
  "college_id": "10",
  "semester_id": "20",
  "text": "导出第7周考勤统计表",
  "request_key": "message-7"
}
```

问题最多4000字符；请求标识为1—64位字母、数字、下划线或连字符，统一小写。同会话、同键、同规范化文本只返回原轮次，不再次调用云端；同键换内容409。客户端应每条新问题生成新键，网络恢复先查询状态。

创建／发送前检查交互配置及 Header 验收门禁；未准备好503，不提前创建记录。读取历史不要求云端当前开启，但仍要求工具入口、原应用连接和本人的有效登录与业务上下文。没有公开运行凭据、平台 AppKey、远端会话编号或运行身份选择接口。

## 持久记录与并发

- `agent_conversation`：实际用户、来源登录会话、学院、学期、环境、配置应用标识、随机远端会话编号、授权上下文摘要、状态及24小时访问期限。访问到期不等于物理删除。
- `agent_turn`：请求键、问题摘要、用户文本、正式回复、运行引用、远端请求编号、排队／发送状态、尝试令牌及排队／发送截止时间。每轮绑定一个独立 `AgentRun`。
- 使用原 `visibility_hash` 和权限计算生成上下文摘要，纳入学院配置修订与学期状态；不是新建角色／授权表。换账号、登录会话、学院或学期404；授权上下文变化拒绝沿用旧历史，迟到回复不保存。
- 同一会话行锁串行准入，一次只允许一个 `QUEUED` 或 `SENDING`，每会话最多100轮。已接入[持久聊天队列](AGENT_CHAT_QUEUE_20261025.md)：按数据库／环境／工具应用控制并发和等待容量，未知结果继续占位。真实 MySQL协调尚未验收。
- `RunService.issue_in_transaction` 不提交父事务；运行与排队轮次同事务持久化。等待期间凭据不可用，领取时复核权限并在同一事务内轮换凭据；提交前构造发送参数，云请求期间不持有数据库会话，含 `expire_on_commit=true` 回归。
- 唯一成功回执才能保存回复；重复或迟到回执不能覆盖已有结果。成功、失败、结果不明都会收回本轮云端工具凭据；原读取作业仍可通过有效来源登录与当前权限执行。
- 网络结果不明或发送过期时记录 `UNCERTAIN`，冻结该远端会话的新发送，不自动重发、不假装取消远端。原轮次可重查，已登记任务可恢复查看；需要继续对话时创建新的独立会话。
- 查询按轮次编号游标分页，返回受控纯文本和本地任务操作。记录不含运行凭据原文；正式回复再次隐藏已知本轮运行凭据。前端仍需按纯文本处理回复，业务操作以返回的受控列表为准。

## 腾讯云变量与传输

基于[已实现的对话适配](ADP_MANAGEMENT_CHAT_TRANSPORT_20261025.md)，将运行凭据及经后端核验的 `college_id`、`semester_id`、Asia/Shanghai 业务日期／时区放入独立 CustomVariables，不拼接到用户问题。业务上下文仅帮助理解口径，不能授予数据权限。工具仍以绑定运行和原服务校验为准。

发送 API 仅登记排队并返回 JSON，消费者获取最终回复后持久化，浏览器通过 GET 查询。未向浏览器转发原始 SSE 或思考／工具过程；客户端超时不等于云端已停止。动态 Header 隔离、变量映射和实际平台日志仍待验收，配置保持空、开关保持false。学期周次等自然语言口径还需结合实际业务数据完成平台端验证。
