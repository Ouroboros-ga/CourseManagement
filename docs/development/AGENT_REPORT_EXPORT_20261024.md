# 智能体统计报表导出准备

日期：2026-10-24。分支：`future/agent-dev`。状态：工具及既有下载链路的本地候选，未部署、未联调腾讯云。管理助手对话界面及下载卡仍待接入。本轮不新建报表存储服务、不发布版本化周报，不把准备成功当作文件已生成。

## 调用与业务边界

新增 MANAGEMENT 工具 `report_attendance_export_prepare`，HTTP/MCP共用原运行身份与工具目录，SELF_SERVICE和后台自动化不可调用。输入为学期字符串ID、周次或完整日期范围、固定报表格式；学院来自运行绑定，身份字段、任意URL、SQL及文件路径不接受。日期范围上限93天，绑定学期不能替换。

| format | 生成与下载入口（带`/api/v1/colleges/{运行学院}`前缀） |
| --- | --- |
| ANALYTICS_XLSX（默认） | `/statistics/attendance/export` |
| DETAIL_DOCX | `/statistics/attendance/export-detail-doc` |
| STUDY_XLSX | `/statistics/attendance/export-study-excel` |

准备时复用 `StatisticsService.attendance_stats` 和原 `statistics.read` 范围，验证查询窗口并返回命中任务数；不把人员、班级明细或文件内容送入模型。工具结果含固定kind、format、标题、window、运行学院及同源相对下载路径，无签名或凭据。

返回 `artifact_status=NOT_GENERATED` 和 `download.requires_login=true`。此时文件尚未生成；“命中任务数”是准备时的读数，后续数据变化后实际下载结果可能不同。

用户点击下载后，前端使用当前登录HTTP客户端请求既有入口，原统计服务重新鉴权、查询并生成Excel/Word。撤权、解绑、切换账号或源数据变化不会被旧准备结果绕过。路径不是访问授权，不可当作无需登录的分享链接。导出统计不隐式授予 `report.generate`，也不登记正式周报版本。

## 对话界面接入要求

1. 识别可信工具调用的结构化结果，显示“已准备导出，点击后生成”，不能显示“已生成文件”。模型回复中的普通链接不视为可信下载操作。
2. 固定映射上述三个格式与路径，只允许同源、固定学院的统计入口。学院必须仍等于当前工作区；不要将模型提供的任意URL交给带Bearer的请求客户端。
3. 点击时调用原登录请求客户端读取二进制，不用普通`href`代替带认证请求。使用服务端Content-Disposition文件名；只有成功取得文件后才显示下载成功。
4. 请求期间账号、学院或授权版本变化时丢弃旧响应；403/404提示重新核对，不能自动切学院或改成全校导出。

这些界面行为仍待实施；本轮通过HTTP测试验证的是后端实际生成及再次鉴权，不代表管理助手已完成用户可操作的对话导出。

## 队列与验证

准备为只读操作，可进入已有持久队列。可见范围摘要复用statistics.read，不要求教师绑定学生；读取历史任务结果时仍复核当前范围。作业只保存下载操作元数据，不保存文件字节或签名，原租约/取消规则保持。

新增19项检查覆盖三种固定格式、身份/URL/格式参数拒绝、学期绑定、日期范围、功能门禁、目录隔离、无报表/文件副作用、真实队列Worker及HTTP工具凭据。实际REST下载测试分别生成并解析三种格式（openpyxl读取两类Excel，python-docx读取Word）；统计Excel确认本院课程标记存在，三类文件均无外院标记，随后撤销学院绑定使下载拒绝。下载测试登录依赖为合成账号，运行凭据验证使用真实运行记录；SQLite及合成数据不能代替生产身份或MySQL验收。

网关/统计范围/授权组合285项通过；扩展三种格式后的工具/合同/统计定向25项通过，Agent模块Ruff及5个相关模块Mypy通过。
