## 运行边界

复用`auto_change_execution`作为源事件和正式改派回执，`agent_run`恢复受限后台身份；新增`agent_workflow_run`只记录云实例归属、派发阶段、租约、查询时间、计数和业务对账结果。它不存运行凭据原文、模型载荷或第二套权限。

每次循环最多发出一次云请求。先落库STARTING和凭据摘要，再释放数据库事务并调用ADP；拿到实例编号后落库WAITING。查询按数据库时间继续，不占用原只读Worker的作业槽。当前按每个环境/工具应用一个派发进程运行，不声称多进程全局精确容量控制。

| 阶段 | 含义与恢复行为 |
| --- | --- |
| STARTING | 创建前已登记；60秒租约过期后进入UNCERTAIN，不再猜测是否已创建 |
| WAITING / POLLING | 保存云实例编号；按下次查询时间领取，读取租约过期可重领，旧尝试不能覆盖新结果 |
| RETRY_WAIT | 仅用于明确拒绝且允许重试的创建错误，最多创建尝试3次；每次轮换凭据 |
| UNCERTAIN | 创建结果不确定，撤销运行写入；原申请保留，不重建云实例 |
| TIMED_OUT | 总期限或查询次数达到上限，撤销写入、转人工；不宣称云实例已取消 |
| OBSERVATION_FAILED | 配置不匹配或查询不能继续，保留实例与错误码，转人工核查 |
| FINISHED | 已获云端终态或明确创建拒绝；业务结果另存outcome，不用云端状态代替改派事实 |

默认同时追踪5个运行、查询间隔2秒、总期限300秒、最多100次查询，受`AGENT_ADP_DISPATCH_LIMITS`约束。未知创建、超时和观测失败仍占用容量，避免云端尚未结束时继续无限派发。已知实例可人工复查终态后释放；没有实例编号的UNCERTAIN需云端人工核查，当前不提供猜测绑定或强行释放入口。

运行凭据有效期同时受总期限约束。策略关闭/授权失效由原领域服务在工具执行时拒绝；明确拒绝后的重试也要重查源申请、策略与当前权限，不因曾经入队继续改派。

## 对账口径

outcome为SUCCEEDED之前，核对源执行回执、申请通过状态、原受派确已撤销、新旧受派属于同一任务、新受派的人员及系统来源一致。新受派后来又被合法调整，不抹去已经成功的历史事件。

云端成功但没有正式改派回执，结果为MANUAL_REQUIRED，保留原受派。云端失败但本地改派已经原子提交，结果仍为SUCCEEDED，同时保留remote_status=FAILED。只有成功标志而回执/受派事实不完整，结果为UNKNOWN，错误码LOCAL_RECEIPT_INVALID，不伪造成功。

环境和工具应用过滤覆盖领取、重试、崩溃回收、容量统计和复查。新源事件记录创建环境；旧记录无法确认来源时保持NULL，不按当前服务器环境自动回填，也不自动派发。配置缺失不会把全部业务申请消耗为失败。

正常消费要求Worker、ADP、自动换班、工具入口开关开启，并配置正确AUTOMATION/change应用及已验收的Header传递。复查可在策略已关闭时执行，但仍须ADP配置有效；不能把诊断能力作为恢复业务写入的通道。
