# 学院申诉预审开关

日期：2026-10-24。开发分支：`future/agent-dev`。状态：本地候选，未部署、默认关闭。入口为管理端“考勤与异议→学生异议”，无待处理申诉时也可设置。

仅向有现行申诉读取/终审能力的教务管理账号展示入口，服务端继续核对实际角色与完整学院范围。个人责任区页面不提供学院开关，不增加新权限体系。

策略按学院统一生效，适用于各学期；开启只影响之后提交的申诉，历史申诉显式发起预审。配置未就绪时不可开启，但可关闭已有策略。配置就绪不是实时运行心跳。关闭不会立即终止已发起的云端处理，结果仍须由服务端核验。

保存携带所见版本，收到合法回执后才更新开关；重复点击不重复提交。冲突、请求失败或回执异常使状态待核对，须显式刷新，不自动重发。学院、账号、授权版本变化及卸载后拦截迟到响应。策略保存期间与正式终审/重新预审互斥，保存成功刷新当前预审并清除原确认。
