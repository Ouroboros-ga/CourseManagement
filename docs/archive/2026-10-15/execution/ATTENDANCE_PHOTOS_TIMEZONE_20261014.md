# 考勤现场照片与 Web 时区修复验收

## 修改

Web 异议页、提交审核页、换班申请与绑定码复用北京时间格式化函数。无偏移 datetime 按后端 UTC 约定解释，显式偏移按实际时刻处理；校历日期不做时区平移。

本人及管理考勤列表/详情新增 `photo_file_ids`，从任务已通过提交批量查询，不产生逐行查询。正常出勤也可关联。学生文件访问需要本人正式考勤、提交名单归属、有效绑定、有效账号和考勤读取权限，沿用文件状态及保留期检查。列表与访问共用关联谓词，ID 始终为字符串。

本次按系统排查、TDD、FastAPI、授权模式、Vue 与完成前验证技能核对，GPT 直接执行，未调用子 agent。契约、权限说明及 OpenAPI 已同步。

## 本次验证

- 后端全量单元测试：240 passed，两个依赖弃用警告；新增照片回归 11 项，覆盖 HTTP 信封、本人访问、他人拒绝、解绑、受限账号、提交状态、名单归属、保留期及 BIGINT ID。
- Web 回归：9 passed，其中时间转换 3 项；Vue 类型检查及生产构建通过。保留已有混合导入、包体积告警。
- 新增关联查询 mypy 通过；新增查询、改动仓储/路由及回归文件的 Ruff 通过。未宣称全仓库静态检查无既有错误。
- 时间及照片回归均先观察到失败，再完成实现并通过；照片接口使用内存 SQLite，不连接业务库或破坏性的 MySQL 集成夹具。
- OpenAPI 导出有既有查课志愿者路由重复 operation ID 警告，路径数量不变。
