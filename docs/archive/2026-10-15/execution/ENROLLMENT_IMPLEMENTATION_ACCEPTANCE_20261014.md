# 固定学院权限、平台管理与学籍交接交付记录

日期：2026-10-14。源码由本地 CourseManagement 开发，远端仓库同步与生产验收分别记录，不以服务器代码替代本地源码。

本轮已完成线上发布及 `admin` 平台赋权，软件测试学院及两个班级全部保留，具体版本、计数、备份和待核定资料见 [线上发布记录](../operations/ENROLLMENT_RELEASE_20261014.md)。备份脚本输出解析另有 4 项发布回归通过。

## 已实现

- 五角色不变。平台管理员为 SUPER_ADMIN 加显式 `administrator_account.manage`，拥有管理员创建、启停、重置密码及平台能力配置入口；默认 seed 不授予平台能力。新旧账号/角色入口均受守卫保护，最后有效管理员和平台管理者保护、乐观版本及会话撤销生效。
- 教师固定唯一学院，拥有本院业务权限；学生负责人依据本人当日学籍和有效任命工作，功能开关由合法教师/管理员配置。学院范围覆盖旧业务列表/计数、详情、缓存、写入与报表，跨院异动只由管理员办理。
- 学籍异动支持转班/转专业/跨院、休学、复学、毕业、退学、生效日期、未来撤销及明确历史纠错。学生 ID、学号和绑定稳定，回溯纠错保留后续区间；当前投影幂等生效。离校本人历史访问暂定十个日历年，不自动物理清除档案。
- 正式课程名单依据明确行政班课源及有效学籍，选修名单保留日期区间。只刷新未来未开始且无提交/截止事实的正式任务；保留已开始和历史快照、人工人数，未知合并来源及人数变动提示管理员核定。未核定归属的旧课程/受派仍参与本人时间冲突。
- 老师可以导出带稳定 ID/版本的 XLSX，上传 XLSX/平铺 ZIP、预览、全量对比、原子确认。缺失学生只提示，不自动删除/归档/恢复；重复身份、外院、版本变化及无效学籍命令阻止整批确认。每批汇总刷新未来名单一次，新增学生同样刷新班级课源。
- Web 提供管理员账号、教师学院、负责人功能及学生交接与学籍界面，显示异动预览、有效区间、中文状态、导入缺失项和待核定任务。

## 迁移与运行边界

新增迁移 `f26a1014e001` 基于 `f26a1014m001`。旧学生只建立当前未核实历史基线；历史名单不反推学院/专业。行政班来源只在稳定导入证据完全匹配时恢复；未知资料留给学校管理员。

初始化学校“绍兴理工学院”、正式学院“人工智能学院（低空技术与工程学院）”、测试学院“软件学院（测试）”；教师 ID 9 绑定正式学院，`admin` 显式开通平台能力。原两个软件学院班级及全部关联学生、账号和业务记录保留。测试学院目前依学院隔离，不自动从全校汇总剔除测试数据。

日期投影命令为 `python -m app.modules.academic.apply_enrollment_changes`，鉴权请求亦补齐到期事件。迁移降级仅在没有学籍变更事实或已确认数据计划时允许；已有新事实后禁止直接删表降级。发布失败先恢复应用指针/配置，数据恢复使用停机前私有备份，不自动覆盖数据库。
